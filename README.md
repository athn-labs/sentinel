# Sentinel

System diagnostic CLI for Linux servers.

## Why?

Sentinel was created to simplify collecting information about a Linux server. Get essential system information using a single command.

## Features

- Display hostname

- Display kernel version

- Display uptime

- Display memory usage in %

- Display disk usage -  check in-use and overall disk space

## Tech Stack

- Python 3

- Linux

- subprocess
